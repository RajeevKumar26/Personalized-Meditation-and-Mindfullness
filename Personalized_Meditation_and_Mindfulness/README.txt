PERSONALIZED MEDITATION AND MINDFULNESS
========================================

Project technology
- HTML
- CSS
- JavaScript
- Browser LocalStorage (for demonstration data)

HOW TO RUN
1. Extract the project ZIP file.
2. Open the project folder.
3. Double-click index.html to open the website in a browser.
4. You can also open the folder in Visual Studio Code and use Live Server if it is already installed.

CREATE AN ACCOUNT
- Select "Create account".
- Enter your name, email and a password of at least 6 characters.
- Then use the same email and password on the Login tab.

MAIN PROJECT FUNCTIONS
- User registration and login
- Profile management
- Create, view, edit and delete meditation sessions
- Create, view, edit and delete schedules/plans
- Search and filter sessions
- Update session status (Pending / Completed)
- Progress and history tracking
- Staff/admin role-based access
- Dashboard
- Responsive layout for desktop and mobile

IMPORTANT TECHNICAL NOTE
This is a beginner-level front-end academic demonstration. User accounts and records are stored in the browser's LocalStorage. It is not production-secure authentication and does not use a real server or database. Do not use a personal or reused password.

CODE STRUCTURE
index.html  - page structure
css/style.css - design and responsive layout
js/app.js - login, records, plans, profile and dashboard functions
